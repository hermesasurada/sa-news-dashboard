# SA HTML 본문 추출 피타폴 (2026-05-21)

## 문제
SA 페이지의 `<p>` 태그 안에 SVG 아이콘, 마크업 요소가 섞여 들어감.
예: `<symbol><path d="M3.763 8.396..."/></symbol>` — 요약용 원문에 SVG 경로가 그대로 포함됨.

## 원인
`<p>` 태그 추출 시 `re.findall(r'<p[^>]*>(.*?)</p>', html)`로 전체 내용을 가져오는데,
SA가 `<p>` 안에 SVG `<symbol>` 요소를 포함하고 있음.

## 해결
```python
# 1. HTML 태그 제거
text = re.sub(r'<[^>]+>', '', p)
# 2. HTML 엔티티 디코딩
text = html.unescape(text)
```

## 개선 사항
- paragraph 수: 8개 → 최대 30개
- 내용 제한: 3000자 → 10000자
- `<article>` 컨테이너 내 `<p>`만 추출 (네비게이션/헤더 제외)

## 참고
SA 뉴스 기사는 본래 짧은 편(3~5문단). 긴 분석 기사도 있지만 뉴스 브리프는 짧음.
요약이 빈약한 경우 기사 자체가 짧은 것일 수 있음.
